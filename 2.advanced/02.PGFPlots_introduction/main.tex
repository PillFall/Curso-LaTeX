\begin{frame}[fragile]
El comando \mintinline{latex}{\addplot} sin opciones se comporta de manera distinta al comando con opciones.

\pause

Cuando \mintinline{latex}{\addplot} no tiene opciones, utiliza una lista de parámetros cíclica (\texttt{cycle list}) por defecto para asignar un estilo «diferente» a cada curva de la gráfica.

\pause

Para que se comporte de manera similar, debemos usar el comando \mintinline{latex}{\addplot+}.

Este funciona igual que \mintinline[escapeinside=||]{latex}{\addplot [<|\textit{options}|>] ...}, con la diferencia de que las opciones se añaden a los argumentos que se habrían utilizado para \mintinline{latex}{\addplot ...} (el elemento de la lista predeterminada).

De esta forma, se pueden combinar \texttt{cycle list} y \texttt{\textit{opciones}}.
\end{frame}
