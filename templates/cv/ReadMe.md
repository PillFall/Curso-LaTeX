# Curriculum Vitae

En estos directorios puedes encontrar algunas plantillas de LaTeX para la generación de una hoja de vida.

Para empezar, puedes compilar los archivos `.dtx` dentro de cada una de las carpetas con LuaLaTeX así:

```shell
cp ../introduction.tex introduction.tex
lualatex cv.dtx
```

Este comando genera la documentación de la clase contenida en el mismo.
Ahora puedes leer el documento generado por este archivo para saber que deberías hacer después.
