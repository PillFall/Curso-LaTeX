# Fuentes Personalizadas, Emojis e Iconos

En este documento se muestran algunas configuraciones para trabajar en LaTeX con fuentes personalizadas, incluyendo el uso de emojis e iconos en el documento.

Antes de poder compilar el documento, es necesario descargar las fuentes que se utilizan, hay dos archivos diseñados y probados para Windows, Linux y MacOS.

- En Windows, ejecute el archivo `fonts.ps1`. Muy probablemente Windows te pida permisos para ejecutarlo.
- En Linux o MacOS, ejecute el archivo `fonts.sh`, para poder ejecutarlo necesitará `curl` y `jq`.
